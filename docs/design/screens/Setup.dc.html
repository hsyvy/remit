Remit
PayPal sandbox

Set up a wallet your agent can’t overspend.

Three steps. Nothing is held or spent until you approve a plan, and you can disconnect at any time.

  1. Connect PayPal

    Connected

    Remit places holds on your PayPal account when you approve a plan. It never stores your card or bank details.

  2. 2

    Connect an agent

    Waiting for the agent

    Add Remit to the agent you already use. It gets four tools and a token, and no access to PayPal.

    "remit": {
  "command": "npx",
  "args": ["tsx", "src/mcp/main.ts"],
  "env": {
    "REMIT_URL": "http://localhost:3000",
    "REMIT_AGENT_TOKEN": "remit_agt_7Qx…3f9c"
  }
}
    Remit will move on as soon as the agent calls get_balance.

    Ask for a first plan

    Claude looks at what you usually buy and proposes a budget with a reason for every line. You review it, change it, and approve it on PayPal.
